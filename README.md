# personal-tools

Small tools for my own machines. Each subdirectory is its own uv project.

| Tool | What it does |
|------|--------------|
| [session-search](session-search/) | Plain-English search over Claude Code + Codex sessions, ranked by Jev |
| [memory-tool](memory-tool/) | Durable Codex chat memory, bounded history, adaptive context resets and evidence retrieval |
| [jev-gate](jev-gate/) | Claude Code PreToolUse hook: regex rules, then Jev flags tool calls that go against your instructions |
